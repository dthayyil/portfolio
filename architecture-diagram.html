Portfolio Application Architecture

Architecture Overview

This portfolio is built as a modern Next.js 15+ application using the App Router architecture. Key design decisions include:

  • Static Site Generation (SSG): Pre-rendered HTML for optimal performance and SEO
  • App Router: File-based routing with React Server Components by default
  • Content Layer: MDX for blog posts with frontmatter metadata
  • SEO-First: Comprehensive structured data, sitemaps, and OpenGraph integration
  • Accessibility: Semantic HTML, ARIA labels, and keyboard navigation
