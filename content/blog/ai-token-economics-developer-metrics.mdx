        <h2 class="text-2xl font-bold text-white sm:text-3xl">Understanding Enterprise AI Token Economics</h2>
        <p class="text-sm leading-relaxed text-slate-400 sm:text-base">Tokens are the fundamental unit of billing for large language models. Input tokens (repository context, open files, and instructions) are processed to generate output tokens (code completions, refactors, and explanations).</p>
      </header>
      <div class="grid items-start gap-6 lg:grid-cols-2">
        <div class="space-y-4">

            <h3 class="font-bold text-cyan-300">📥 Input tokens vs. output tokens 📤</h3>
            <p class="text-sm leading-relaxed text-slate-300">Input is the context window payload: file trees, open buffers, project rules, and prompts. Output is the generated code and explanations. Output tokens typically cost 3×–4× more because generation is sequential.</p>

    <section id="framework" class="space-y-8 rounded-2xl border border-slate-800 bg-slate-900 p-6 shadow-xl sm:p-8">
      <header class="space-y-3">
        <div class="text-sm font-semibold uppercase tracking-wider text-teal-400">📊 Enterprise Playbook</div>
        <h2 class="text-2xl font-bold text-white sm:text-3xl">The 4-Tier Measurement Framework</h2>
        <p class="text-sm leading-relaxed text-slate-400 sm:text-base">Balance adoption telemetry, cost hygiene, engineering outcomes, and business value. Treat usage metrics as diagnostic guardrails—not individual performance targets.</p>
      </header>
      <div class="grid gap-5 md:grid-cols-2 lg:grid-cols-4">
        <article class="space-y-3 rounded-xl border-t-4 border-cyan-500 bg-slate-950 p-5 shadow-lg">
          <div class="flex items-center justify-between"><span class="text-xs font-bold uppercase tracking-wider text-cyan-400">Tier 1 · 15%</span><span>📱</span></div>
          <h3 class="text-lg font-bold text-white">Tool Adoption &amp; Telemetry</h3>
          <p class="text-xs text-slate-400">Verify license utilization and meaningful engagement.</p>
          <ul class="space-y-2 border-t border-slate-800 pt-3 text-xs leading-relaxed text-slate-300"><li><strong>WAU / MAU:</strong> Active user engagement days.</li><li><strong>Acceptance rate:</strong> 25%–35% inline suggestion benchmark.</li><li><strong>Feature breadth:</strong> Inline, chat, and agentic edits.</li></ul>
        </article>
        <article class="space-y-3 rounded-xl border-t-4 border-blue-500 bg-slate-950 p-5 shadow-lg">
          <div class="flex items-center justify-between"><span class="text-xs font-bold uppercase tracking-wider text-blue-400">Tier 2 · 20%</span><span>🧹</span></div>
          <h3 class="text-lg font-bold text-white">FinOps &amp; Prompt Hygiene</h3>
          <p class="text-xs text-slate-400">Keep compute efficient and context focused.</p>
          <ul class="space-y-2 border-t border-slate-800 pt-3 text-xs leading-relaxed text-slate-300"><li><strong>Model routing:</strong> Lightweight vs. reasoning models.</li><li><strong>Tokens per merged PR:</strong> Spot retry loops.</li><li><strong>Cache hit rate:</strong> Measure context reuse.</li></ul>
        </article>
        <article class="space-y-3 rounded-xl border-t-4 border-purple-500 bg-slate-950 p-5 shadow-lg">
          <div class="flex items-center justify-between"><span class="text-xs font-bold uppercase tracking-wider text-purple-400">Tier 3 · 35%</span><span>🚀</span></div>
          <h3 class="text-lg font-bold text-white">DORA &amp; Output Metrics</h3>
          <p class="text-xs text-slate-400">Measure delivery speed without sacrificing quality.</p>
          <ul class="space-y-2 border-t border-slate-800 pt-3 text-xs leading-relaxed text-slate-300"><li><strong>PR lead time:</strong> Commit-to-merge acceleration.</li><li><strong>Change failure rate:</strong> Watch defect trends.</li><li><strong>Test coverage:</strong> Unit-test expansion.</li></ul>
        </article>
        <article class="space-y-3 rounded-xl border-t-4 border-teal-500 bg-slate-950 p-5 shadow-lg">
          <div class="flex items-center justify-between"><span class="text-xs font-bold uppercase tracking-wider text-teal-400">Tier 4 · 30%</span><span>💡</span></div>
          <h3 class="text-lg font-bold text-white">Business ROI &amp; Value</h3>
          <p class="text-xs text-slate-400">Connect engineering leverage to organizational impact.</p>
          <ul class="space-y-2 border-t border-slate-800 pt-3 text-xs leading-relaxed text-slate-300"><li><strong>Net value:</strong> Hours saved less tool costs.</li><li><strong>Onboarding speed:</strong> Time-to-first-commit.</li><li><strong>Retention:</strong> Reduce cognitive strain.</li></ul>
        </article>
      </div>
      <div class="rounded-xl border border-cyan-500/30 bg-cyan-950/30 p-4 text-sm leading-relaxed text-cyan-100"><strong class="text-cyan-300">Measurement principle:</strong> Adoption is a signal for enablement—not a quota. Pair every usage metric with a delivery or quality outcome.</div>
    </section>
